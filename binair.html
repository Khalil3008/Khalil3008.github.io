Het binaire stelsel

Computers werken met bits. Een bit kan de waarde 0 of 1 hebben. Het binaire stelsel gebruikt daarom alleen de cijfers 0 en 1.

Hoe werkt het?

Elke positie in een binair getal heeft een waarde. Van rechts naar links zijn die waarden 1, 2, 4, 8, 16, 32, 64 en 128.

Bij een 1 tel je de waarde van die positie mee. Bij een 0 tel je die waarde niet mee.

Voorbeeld: van binair naar decimaal

We gebruiken het binaire getal 00101010.

Positie 128 64 32 16 8 4 2 1
Bit 0 0 1 0 1 0 1 0

We tellen de positiewaarden op waar een 1 staat: 32 + 8 + 2 = 42.
